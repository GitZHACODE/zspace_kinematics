# Robot models

Place URDF robot descriptions here if you want to keep application models beside this
library. The `abb_irb4600_40_255/` directory contains the IRB 4600-40/2.55 model and
its local visual USD mesh references. See its README for the base and flange links.

All URDF dimensions must be in metres and joint limits must be in radians (or metres
for prismatic joints), as required by URDF and KDL.
